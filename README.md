# NUGAGF — Nigerian University Generative AI Governance Framework**A governance framework for mitigating Generative AI misuse in Nigerian public universities.**Developed as the practical artefact accompanying the seminar paper *"Design and Implementation of a Governance Framework for Mitigating Generative AI Misuse in Nigerian Public Universities"* (MIT 8212 — Seminar: Industry Applications and Management in Information Technology, Miva Open University).## Why this existsNigerian public universities are experiencing rapid, largely ungoverned adoption of Generative AI tools (ChatGPT, Gemini, Copilot, etc.) in academic assessment. Existing responses rely heavily on AI-text detection software, but peer-reviewed evidence (Weber-Wulff et al., 2023; Elkhatat et al., 2023) shows these tools are not reliable enough to serve as a stand-alone enforcement mechanism. NUGAGF proposes a governance-first alternative, adapted from the NIST AI Risk Management Framework and aligned with the Nigeria Data Protection Act (NDPA) 2023.## What's in this repository|File|Purpose||-|-||`POLICY-TEMPLATE.md`|A ready-to-adapt institutional Generative AI Use Policy||`COMMITTEE-TOR.md`|Terms of Reference for the AI Governance Committee||`ASSESSMENT-RISK-MAPPING.md`|Tool for classifying GenAI exposure risk by assessment type||`NDPA-COMPLIANCE-CHECKLIST.md`|Checklist mapping framework activities to NDPA 2023 / GAID 2025 obligations||`/docs/framework-overview.md`|Full description of the four NUGAGF pillars (Govern, Map, Measure, Manage)|## The Four Pillars1. **Govern** — Institutional ownership, a published policy, and a cross-functional oversight committee.2. **Map** — Faculty-by-faculty audit of where GenAI intersects with assessment.3. **Measure** — A layered evidence model that does *not* rely solely on unreliable detection software.4. **Manage** — Graduated, proportionate response procedures and continuous staff/student training.## How to use this repository1. Copy `POLICY-TEMPLATE.md` and replace bracketed placeholders with your institution's details.2. Use `ASSESSMENT-RISK-MAPPING.md` to audit your own faculties' assessment types.3. Route the policy through your institution's normal approval process (Senate/Academic Board).4. Use `NDPA-COMPLIANCE-CHECKLIST.md` before deploying any detection or monitoring tool.## CitationIf referencing this framework academically, cite it as part of the accompanying seminar paper (see `/docs/framework-overview.md` for full source list).## LicenseReleased for academic and institutional adaptation.
