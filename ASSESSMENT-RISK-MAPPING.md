# Assessment Risk Mapping Tool

Use this tool to classify each course assessment's exposure to Generative AI misuse, and to identify a recommended mitigation approach. Faculties should complete one row per assessment type per course.

## How to score

Rate each assessment on three factors (Low / Medium / High):

* **Take-home exposure** — Is the assessment completed unsupervised, outside an exam hall?
* **Text-generation susceptibility** — Can GenAI plausibly produce a passable answer with minimal subject expertise?
* **Verifiability** — How easily can a lecturer confirm the submission reflects the student's own understanding (e.g., through drafts, oral defense, or in-class components)?

**Overall Risk = High** if two or more factors are rated High.

## Mitigation options by risk level

**High risk:**

* Add an oral defense/viva component.
* Require staged submission (outline → draft → final) to create a verifiable process trail.
* Redesign toward applied, context-specific tasks (e.g., analysis of a provided dataset or local case study) that are harder to answer generically.

**Medium risk:**

* Require a short reflective or disclosure statement.
* Spot-check a sample of submissions for oral follow-up.

**Low risk:**

* No change required; continue routine monitoring.

## Notes

* This tool should be completed by each Department/Faculty Board at the start of each academic session and updated whenever a course's assessment structure changes.
* Results should be submitted to the AI Governance Committee as part of its semester reporting cycle.
